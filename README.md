# 사내 프로그램 웹 전환
> 사내 프로그램의 웹 전환 작업을 위한 화면 및 콘텐츠 개발

<br/>

## 📝 프로젝트 소개

기존 사내 프로그램의 웹 전환을 위해 기본 화면을 구축하고
외부 API를 연동하여 날씨와 환율 정보를 제공하는 배너를 개발했습니다.

<br/>

## 주요 기능

- **소식 배너** - 슬라이드 형식으로 최신 소식을 제공합니다.
- **날씨 정보** - 현재 기온과 날씨를 비롯해 시간대별 예보를 제공합니다.
- **환율 정보** - 당일 환율 정보를 제공합니다.
